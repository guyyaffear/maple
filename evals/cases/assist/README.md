# Assist cases

Review comments written against a real running application with Maple mounted
in it, reading the screens the way a reviewer does. Not written from the
pillars, and not written from the keyword baseline's heuristics — writing cases
from the thing being tested is the failure `../../README.md` bans.

**Anonymised, not rewritten.** Account handles, host names and the application's
own name are replaced; the English is exactly as it was written. A comment's
phrasing is the input.

**Provenance.** `by` records who wrote each one: `maintainer` for a comment
written in the overlay and posted to a real pull request, `reviewer` for one
written against the same running screens in the same session. Nothing here was
invented to fit a scorer.

**Partial labels are deliberate.** A case labels the pillars whose rung is not
arguable and leaves the rest out, and a scorer only scores what is labelled.
Guessing at a rung to fill a field would score the guess, not the model.
